TAU Lounge Restaurant — упрощённая статическая версия для GitHub Pages

Загрузка:
1. Откройте репозиторий taulounge/taupavlodar.
2. Удалите старые файлы проекта (если они остались).
3. Add file → Upload files.
4. Перетащите СОДЕРЖИМОЕ этой папки: index.html, order.html, style.css, menu.js, README.txt и папку assets.
5. Commit changes.
6. Settings → Pages → Deploy from a branch → main → /(root) → Save.

Это статический сайт: Node.js, React, Vite и GitHub Actions не нужны.
Главная и меню: index.html
Корзина и оформление: order.html
Логотип: assets/tau-logo.jpg
